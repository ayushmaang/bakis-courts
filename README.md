# Baki's Courts website

> **Draft branch:** This branch previews possible court-operator contact wording. It is not the live site, and the operator claim is not verified. See [DRAFT_OPERATOR_CHECKLIST.md](DRAFT_OPERATOR_CHECKLIST.md) before considering publication.

A static, single-page independent visitor guide for Baki's Courts at Belmont Trace Park in Brambleton, Virginia. The live site is [ayushmaang.github.io/bakis-courts](https://ayushmaang.github.io/bakis-courts/). Open `index.html` locally or serve this folder with any static web server.

## Publishing on GitHub Pages

This folder is published from the `main` branch of [ayushmaang/bakis-courts](https://github.com/ayushmaang/bakis-courts) using GitHub Pages.

## Content and imagery

- Park amenities, access hours, visitor eligibility, and trail guidance were checked against published park information on October 6, 2026. They should be rechecked regularly.
- The court pin is linked to the [Google Maps listing](https://maps.app.goo.gl/x3TqVsLALX3XitCE9) and [Waze listing](https://www.waze.com/live-map/directions/us/va/brambleton/bakis-courts?to=place.ChIJYZchGctBtokRF9LBCcch_JY).

This site is an independent guide and is not operated by park management. The published access guidance should be rechecked periodically.

The +1 (571) 295-2452 number is labeled as the website contact, not the park or court operations line. Do not add the website phone to the court's `Place` structured data or present the site as park-operated without independent confirmation.

The page includes `WebPage` and `Place` structured data describing the guide and court separately. It does not claim that the guide is the official park site or that the court is a public business.
